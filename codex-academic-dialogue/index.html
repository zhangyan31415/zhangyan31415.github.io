RESEARCH QUESTION

为什么区内很准，区外却直接炸掉？

原模型只在第一 BZ 的少量点上拟合低能子空间，却使用最高八阶多项式。评估半径从训练区的约 0.577 扩展到 1.5 后，高阶项可能被放大数十到上千倍。

理想的周期关系
H(k + G) = SG H(k) SG†

但有限 Q 截断使 SG 成为 partial isometry。关键问题不是公式是否成立，而是缺失子空间中的高阶分支没有被 loss 约束。

CURATED TRANSCRIPT

从追问到可复核结论

以下保留原对话的推理顺序；相邻的运行播报和重复表述已合并。

  1. 01
    研究者

    先确认代码究竟在拟合什么

    “现在 kp model 加权的时候，用的就是用户给的点吗？”

    Agent 沿代码数据流核对：完整矩阵、one-sided 与 two-sided 三类损失只在指定的 3 个 k 点计算。这里的权重是损失项权重，不是 k 点之间的权重。

  2. 02
    研究者

    把问题从第一 BZ 推到第二 BZ

    “能不能用 sewing 把 Heff(k) 变成近似的 Heff(k+b₁)，加入拟合，防止外面炸掉？”

    Agent 先验证有限 Q 基底：152 维空间中，平移 sewing 只有 112 维可匹配。共同子块协变到机器精度，但缺失的 40 维恰好没有受到约束。

  3. 03
    共同实验

    先不改核心代码，直接生成区外训练数据

    把路径末点改为 Γ+b₁，重新生成 TAPW 与低能模型。

    单独加入区外路径把 1.5b₁ 处最高带从 +9.246 eV 压到 −2.131 eV；再给临近末点加权后达到 −4.750 eV，但仍有约 1.465 eV 的最大周期误差。

  4. 04
    研究者

    用反例检验解释

    “如果用 q05 呢？不用 G₁？你试试。”

    扩大 Q 截断却不提供区外数据，结果并未改善：q05 在 1.5b₁ 仍升至 +9.403 eV。由此排除“只要扩大 Q shell 就会自动稳定”的解释。

  5. 05
    研究者

    要求严格消融

    “不加权会不炸吗？你试过吗？”

    完全去掉 one-sided 与 two-sided 权重后，灾难性正能量发散消失，1.5b₁ 处回到 −4.370 eV。问题由“可能与权重有关”收缩为可定量定位的病态外推。

  6. 06
    Agent

    从现象进入根因

    逐类权重消融、条件数比较与多项式逐阶展开。

    one-sided 是主要爆带驱动力；two-sided 使拟合矩阵最病态。4、5 阶项首先把顶带推过零，6 阶继续放大，说明问题来自强局部约束与无正则高阶外推的组合。

  7. 07
    共同实现

    把物理判断变成代码约束

    新增 reciprocal sewing、degree ridge 与区外能量损失。

    约束不再只描述第一 BZ 内的局部精度，而是显式惩罚高阶响应并比较折回后的区外能量。每个新机制都用独立配置与宽区能带复算。

  8. 08
    研究者

    继续攻击新方案的边界

    “加到 2b₁、3b₁ 呢？还要看 −4b₁ 到 4b₁，以及 GMKG 和 Heff 的对比。”

    更多 sewing shift 反而更差，因为可匹配子空间从 112 维降到 72、32 维。这个负结果促使方案转向覆盖完整谱的 nonlinear energy loss。

ROOT CAUSE

不是权重写错，而是目标函数在奖励错误的外推

代码确认残差行乘的是 √w，不是把权重重复平方。真正的问题是归一化后，少数低能矩阵元的有效权重远高于其余 Hamiltonian，拟合器会牺牲全矩阵来换取三个点上的局部精度。

NEGATIVE RESULTS

三个听起来合理、但被数据否定的方案

负结果保留在记录里，因为它们决定了下一步不能再沿哪条路线浪费计算。

H1否定

扩大 Q shell 就够了

q05 的模型维数从 152 增到 248，但 1.5b₁ 最高带从 +9.246 eV 变为 +9.403 eV，周期误差更大。

H2否定

在 M/K 附近多放点就能稳定

局部 RMS 略有改善，区外却恶化到 +11.654 eV；这是权重重新分配，不是周期性恢复。

H3否定

不断增加 sewing shift 会单调改善

shift 越远，共同 Q 子空间越小；到 3b₁ 时宽区最高带反而达到 155.097 eV。

IMPLEMENTATION

把科学判断写进拟合目标

Agent 在独立分支实现两类线性约束，随后加入覆盖完整能谱的 nonlinear energy loss。每类机制都能通过配置开关独立消融。

A / reciprocal sewing
Lsew = ΣG,k wG ‖PGHmodel(k+G)PG − SGHeff(k)SG†‖²

只比较有限 Q 基底中能够被倒格矢平移匹配的共同子空间。

B / degree ridge
Lridge = Σj λdⱼ|θj|²,   λd = λ₄(d−3)²

惩罚归一化后的高阶响应幅度，而不是量纲依赖的裸系数。

FINAL EXTENSION

完整谱需要能量层面的区外约束

partial sewing 约束不到缺失子空间。最终新增的 nonlinear loss 直接要求区外 top bands 接近折回第一 BZ 后的 Heff 能量，并保留 matrix、ridge 与 sewing 三项。
