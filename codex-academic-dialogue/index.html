RESEARCH QUESTION

为什么区内很准，区外却直接炸掉？

原模型只在第一 BZ 的少量点上拟合低能子空间，却使用最高八阶多项式。评估半径从训练区的约 0.577 扩展到 1.5 后，高阶项可能被放大数十到上千倍。

理想的周期关系
H(k + G) = SG H(k) SG†

但有限 Q 截断使 SG 成为 partial isometry。关键问题不是公式是否成立，而是缺失子空间中的高阶分支没有被 loss 约束。

1. 如果目标是画能带或计算能量：先把任意 \(k\) fold 回第一 BZ，再求本征值。能量本来就应该周期，不需要 sewing。

Agent
### Annotation 1

这两个式子来自“无限 Q 基组的平移协变关系”在当前有限 Q 集合上的投影。

设当前有限 Q 集合为 \(\Lambda\)。并非所有 \(Q\in\Lambda\) 平移后仍在集合内，因此先定义可匹配部分：

\[
\Lambda_s(G)=\{Q\in\Lambda\mid Q+G\in\Lambda\},
\qquad
\Lambda_t(G)=\Lambda_s(G)+G.
\]

有限 sewing matrix 是

\[
S_G=
\sum_{\alpha,a,Q\in\Lambda_s(G)}
|\alpha,a,Q+G\rangle
\langle\alpha,a,Q|.
\]

它不是幺正矩阵，而是 partial isometry。对应两个投影算符：

\[
P_s=S_G^\dagger S_G,
\qquad
P_t=S_GS_G^\dagger.
\]

其中 \(P_s\) 选出能够被平移的 source Q，\(P_t\) 选出平移后落到的 target Q。当前 q04 中两者 rank 都是 112。

模型矩阵元依赖 \(k-Q\)，所以对于能够匹配的 \(Q,Q'\)：

\[
H_{Q+G,Q'+G}(k+G)=H_{Q,Q'}(k).
\]

把所有这些矩阵元写成矩阵形式就是

\[
P_tH(k+G)P_t
=
S_GP_sH(k)P_sS_G^\dagger.
\]

而因为

\[
S_G=S_GP_s,\qquad S_G^\dagger=P_sS_G^\dagger,
\]

所以右侧可以简写为

\[
P_tH(k+G)P_t=S_GH(k)S_G^\dagger.
\]

这就是第一个公式左侧为什么有 \(P_t\)：我们只能预测 \(k+G\) 处落在 sewing image 内的矩阵块。

现在拟合目标只有第一 BZ 的 \(H_{\rm eff}(k)\)，所以把它通过相同 sewing 搬到 \(k+G\)：

\[
H_{\rm eff}^{\rm sewn}(k+G)
=
S_GH_{\rm eff}(k)S_G^\dagger.
\]

它已经自动满足

\[
P_tH_{\rm eff}^{\rm sewn}P_t
=
H_{\rm eff}^{\rm sewn},
\]

因此右侧不需要再显式写 \(P_t\)。最终比较的就是

\[
P_tH_\theta(k+G)P_t
\quad\text{与}\quad
S_GH_{\rm eff}(k)S_G^\dagger.
\]

不能去掉左边的 \(P_t\)，因为右侧在剩余 40 维补空间里是零；这些零只表示“sewing 没有提供目标”，不表示真实 Hamiltonian 应该为零。

还有一个重要结论。当前 model 在 common block 上已经精确满足平移协变，因此

\[
\begin{aligned}
&P_tH_\theta(k+G)P_t
-S_GH_{\rm eff}(k)S_G^\dagger\\
&=
S_G\bigl[H_\theta(k)-H_{\rm eff}(k)\bigr]S_G^\dagger.
\end{aligned}
\]

进一步等价于第一 BZ 的 matched source block：

\[
\left\|
P_tH_\theta(k+G)P_t-S_GH_{\rm eff}(k)S_G^\dagger
\right\|_F
=
\left\|
P_s[H_\theta(k)-H_{\rm eff}(k)]P_s
\right\|_F.
\]

### Annotation 1：怎么加入 sewing 约束

\mathcal L_{\rm sew}

### Annotation 1

“把 \(k\) 折回第一布里渊区”是指：对于区外的点，不直接计算高阶多项式 \(H_{\mathrm{eff}}(k)\)，而是减去一个倒格矢，把它搬回模型可靠的区域。

例如沿 \(b_1\)：

\[
k=t b_1,\qquad
\bar k=(t-n)b_1,\qquad
t-n\in[-0.5,0.5),
\]

其中 \(n\) 是整数，\(G=n b_1\)。于是

\[
k=\bar k+G.
\]

理论上完整基组满足

\[
H(\bar k+G)=S_GH(\bar k)S_G^\dagger.
\]

因此：

- 只看能量时，直接用
  \[
  E_m(k)=E_m(\bar k),
  \]
  即能带每隔 \(b_1\) 周期重复。
- 需要波函数、轨道成分或谱权重时，再用 sewing matrix：
  \[
  |\psi_m(k)\rangle=S_G|\psi_m(\bar k)\rangle.
  \]

比如：

\[
1.3b_1\rightarrow0.3b_1,\qquad
2.8b_1\rightarrow-0.2b_1.
\]

现在“炸掉”是因为我们直接把多项式模型外推到 \(2b_1、3b_1、4b_1\)。折回方法则始终只在 \([-0.5b_1,0.5b_1]\) 内计算，所以不会出现 100–150 eV 的多项式发散。

但这相当于按倒格矢周期延拓，不是在改善区外多项式本身。有限 \(Q\) 基底下 \(S_G\) 也不是完整酉矩阵，因此能量可以安全周期复制，若要可靠的区外波函数和谱权重，仍需要扩大 \(Q\) shell。

研究者
那现在的代码不是可以非线性吗？把能量加进来算loss吗？
Agent
可以，而且这条路比继续堆 sewing matrix 更直接。

当前代码已经支持 nonlinear energy loss，流程是：

\[
L=L_{\text{matrix}}+
w_E\sum_{k,n}
\left[\varepsilon_n^{\text{model}}(k)-
\varepsilon_n^{\text{target}}(k)\right]^2 ,
\]

并用 Hellmann–Feynman 公式计算解析梯度：

\[
\frac{\partial\varepsilon_n}{\partial c_j}
=\langle u_n|\partial H/\partial c_j|u_n\rangle .
\]

配置接口就是：

```yaml
fit:
  method: nonlinear
  kpoints: [...]
  band_kpoints: all
  bands: 10
  band_loss_weight: 1.0
  max_steps: 50
```

但刚才 \(\pm b_1,\pm2b_1,\pm3b_1\) 三组实验用的是 `method: linear`，所以能量根本没有进入 loss，只有矩阵元、ridge 和 sewing loss。

现有 nonlinear 还有两个限制：

- `band_kpoints` 只能选择已有 Heff 数据中的点，不能直接写任意 \(k+2b_1\)、\(k+3b_1\)。
- nonlinear 阶段目前没有重新加入我们新增的 ridge/sewing loss，优化后可能破坏线性阶段的约束。

真正适合这个问题的 loss 应该是：

\[
L=L_{\rm Heff}^{\rm 1BZ}
+\lambda_{\rm ridge}L_{\rm ridge}
+\lambda_{\rm sew}L_{\rm sew}
+\lambda_E
\sum_{k\in{\rm 1BZ},G,n}
\left[
\varepsilon_n^{\rm model}(k+G)
-\varepsilon_n^{\rm Heff}(k)
\right]^2 .
\]

其中 \(G=\pm b_1,\pm2b_1,\pm3b_1\)。这样直接要求区外 top-10 能量等于折回第一布里渊区后的 Heff 能量，能约束造成爆炸的完整 152 维谱，不再受 sewing 重叠子块只有 112/72/32 维的限制。

而且不能只加 \(b_1,2b_1,3b_1\) 三个端点，最好把 \((-4b_1,4b_1)\) 上的一批点都加入，否则高阶多项式仍可能在采样点之间炸掉。这个方向值得直接做。
